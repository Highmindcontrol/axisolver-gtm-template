# AxiSolver — Google Tag Manager Template                                            
                                                                                
  Template officiel [Google Tag Manager](https://tagmanager.google.com) pour installer 
  **AxiSolver** sur n'importe quel site en 30 secondes, sans toucher au code.   
                                                                                       
  AxiSolver est un assistant IA qui accueille les visiteurs de votre site, répond à
  leurs questions 24h/24, et transmet les leads qualifiés à votre équipe. Site officiel
   : https://axisolver.app                                                             
                                                                                       
  ## Installation (côté utilisateur)                                                   
                                                                                       
  1. Ouvrir votre conteneur Google Tag Manager                                         
  2. Dans **Templates** → **Tag Templates** → **Search Gallery**                       
  3. Chercher « **AxiSolver** »                                                        
  4. Cliquer **Add to workspace**                                                      
  5. Créer un nouveau tag utilisant le template                                        
  6. Déclencheur : **All Pages** (ou votre scope)                                      
  7. Coller votre **site_id** AxiSolver (visible sur https://axisolver.app/dashboard)  
  8. Enregistrer, publier le conteneur                                                 
                                                           
  Durée totale : 30 secondes.                                                          
                                                                                
  ## Comment récupérer son `site_id`                                                   
                                                   
  Créer un compte gratuit sur https://axisolver.app, créer un site, votre `site_id`    
  apparaît dans l'URL du dashboard et dans la section Installation.

  ## Sécurité et confidentialité                                                       
                                                                                       
  Le template demande une seule permission : **injecter le script                      
  `https://axisolver.app/v1.js?siteId=...`** sur votre site. Aucune autre donnée n'est 
  collectée par le template lui-même.                                                  
                                                                                
  Les conversations entre AxiSolver et vos visiteurs sont traitées par le backend      
  AxiSolver conformément à notre [politique de                                  
  confidentialité](https://axisolver.app/confidentialite).
